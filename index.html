01 /

理解原理，也动手验证

课程连接自然语言处理基础与现代大语言模型，覆盖数据、模型、训练、评测和应用。建议具备 Python 编程、概率与矩阵运算以及机器学习入门知识。

01

解释模型机制

从分词与语言建模，到注意力和 Transformer，说明表示方式、训练目标与生成过程之间的联系。

02

完成可复现实验

实现小规模模型，检查数据与代码，在明确的计算预算下训练、评测并比较不同方案。

03

用证据形成判断

提出可回答的问题，设置基线与对照，分析失败和局限，把实验结果写成可核查的结论。

04 /

围绕一个问题，建立自己的证据

每位同学独立完成一个 NLP 或 LLM 项目。优先从自己的兴趣提出问题，也可以参考课程的 48 个候选方向。所有选题采用相同的个人项目要求。

项目须包含实现、实验或经过测试的成果，以及有意义的比较和分析；单纯文献综述不能替代实践。优先选择 CPU 实验或短时 GPU 运行，并明确数据、算力和成本。

提出自选题，或浏览 48 个方向↗
